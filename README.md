# ביס לי – גרסה 1

אפליקציית HTML/CSS/JS פשוטה שעובדת בדפדפן ושומרת את כל הנתונים ב-localStorage.

## מה יש בגרסה הזו
- כרטיס יומי עם 7–9 תחנות אכילה.
- מתחיל תמיד בקפה לפי הגדרת "קפה בוקר" (חם/קר).
- מנסה להגיע לטווח 1,100–1,300 קלוריות.
- לפחות פרי אחד, מתוק אחד מפורט וארוחה אחת.
- כפתור "כרטיס אחר".
- מאגר מנות עם הוספה, עריכה, הפעלה/כיבוי ומחיקה.
- מאגר ראשוני לפי הרשימה שסוכמה.

## איך מפעילים
פשוט פותחים את index.html בדפדפן.

## GitHub Pages
מעלים את index.html, style.css, app.js לריפו ומפעילים Pages.


## אייקון
הגרסה הזו כוללת:
- favicon לדפדפן
- apple-touch-icon למסך הבית באייפון
- manifest עם אייקונים 192x192 ו-512x512

אחרי העלאה ל-GitHub Pages, אפשר לפתוח את האתר באייפון ולבחור "הוסף למסך הבית".


## תיקון גרסה
פריטי בסיס כמו פיתה כוסמין, לחמניית כוסמין ופריכית אינם מוצעים יותר כמנה בפני עצמם.
הכרטיסים משתמשים רק בפריטים שאפשר באמת לאכול כהצעה שלמה, למשל:
- פיתה כוסמין + חומוס + חביתה
- 2 פריכיות + קוטג׳
- לחמניית כוסמין + חרדל + סלמי

הגרסה גם מנקה אוטומטית את פריטי הבסיס מה-localStorage של גרסאות קודמות.


## שינוי בגרסה 1.2
- קטגוריית "פרי" הוסרה ממסך הוספה/עריכה.
- "פרי" נשאר פריט גמיש אחד במאגר.
- מאחורי הקלעים ביס לי עדיין דואגת שלפחות פרי אחד יופיע בכרטיס היומי.
- משתמשים מגרסאות קודמות עוברים אוטומטית למבנה החדש.


## שינוי בגרסה 1.3 — מבנה היום
המחולל עובד עכשיו לפי קצב יומי קבוע:
- 07:30 קפה לפי העדפת חם/קר.
- 17:00 קפה נוסף לפי אותה העדפה.
- רק אחת משתי אפשרויות לארוחות:
  1. ארוחה גדולה אחת בלבד (320+ קלוריות), ובמשבצת השנייה נשנוש/בוקר/מתוק.
  2. שתי ארוחות קטנות (פחות מ-320 קלוריות), אחת בצהריים ואחת בערב.
- 21:00 לעולם אינו ארוחה — רק נשנוש/מתוק/בוקר קל.
- לפחות פרי אחד ביום נשמר כחוק פנימי.
- המחולל נותן עדיפות חזקה לטווח 1,100–1,300 קלוריות.
